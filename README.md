# 🏡 UrbanKeys – Real Estate Landing Page

**Find Your Space. Discover Your Future.**

UrbanKeys is a modern and responsive real estate landing page designed to provide an engaging online experience for users exploring real estate opportunities.

The website focuses on clean UI design, smooth animations, intuitive navigation and responsive layouts to create an attractive digital presence for a real estate brand.

## ✨ Features

- **Modern Landing Page** – Clean and visually appealing real estate website design.
- **Responsive Design** – Adapts to different screen sizes, including desktops, tablets and mobile devices.
- **Smooth Animations** – Interactive transitions and animations for an engaging experience.
- **Property Showcase** – Visually presents real estate offerings.
- **Intuitive Navigation** – Simple and user-friendly navigation.
- **Optimized UI/UX** – Focuses on usability, accessibility and visual consistency.

## 🛠️ Tech Stack

- React.js – Component-based frontend development
- Vite – Fast development and build tool
- Tailwind CSS – Styling and responsive layouts
- React Router DOM – Navigation
- React Icons – Icon library
- React Slick – Carousel and slider components

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/rathi-maya/urbanKeys.git
```

### 2. Navigate to the Project Directory

```bash
cd urbanKeys
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build for Production

```bash
npm run build
```
